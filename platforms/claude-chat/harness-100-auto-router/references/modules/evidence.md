# evidence

주장마다 가장 가까운 원자료나 실행 관찰을 연결한다. 파일은 경로와 SHA-256을, 실행은 재현 명령·종료 코드·출력 위치를 기록한다. 민감한 값은 보고서로 복사하지 않는다.

사실·가정·미확인을 구분하고 출처의 기준 시점을 유지한다. 과거 보고서는 주장으로만 다루며 현재 상태는 다시 확인한다. 접근 불가와 파일 부재를 구분한다.

재검증 횟수는 작업 식별자로 한 ledger에 기록한다(`python -m harness100 ledger status|record --task-id ...`). ledger를 읽을 수 없거나 무결성 검사가 실패하면 횟수를 새로 시작하지 않고 "한도 강제 미검증"으로 보고한다. 보고서 작성 자체를 기능 검증 완료로 처리하지 않는다.
