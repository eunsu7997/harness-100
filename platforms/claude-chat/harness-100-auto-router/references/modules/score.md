# score

사용자가 점수 평가를 요청했을 때만 적용한다. 사용자 기준이 있으면 우선하고, 산출 전에 검사 범위와 배점을 밝힌다.

| 항목 | 배점 | 필요한 실행 증거 |
| --- | --- | --- |
| 자동 선택 `routing` | 25 | 정상·반례 요청의 기대 결과와 실제 라우팅 결과 |
| 권한과 안전 `safety` | 25 | 금지 조건·읽기 전용·악성 Git 설정·승인 검사 |
| 회귀와 재현성 `regression` | 20 | 단위 테스트 종료 코드, 반복 실행 일치, 패키지 검사 |
| 증거 관리 `evidence` | 15 | 점수 위조·ledger 우회·누락 증거 반례 |
| 플랫폼 적용 `platforms` | 15 | 실제 설치·인식·호출·차단 관찰 |

점수는 품질 게이트(`python -m harness100 qgate --out <폴더>`)가 직접 실행해 남긴 원 로그에서만 계산한다. 항목 안의 검사마다 같은 몫을 주고 PASS만 득점한다. FAIL·미검증은 0점이며, 로그에 없는 검사는 미검증이다. 점수 보고서·README·사용자가 전달한 passed 값은 점수에 쓰지 않는다. 게이트가 실행할 수 없는 플랫폼 검사는 별도 실측 로그가 없으면 미검증이다.

총점과 함께 미검증 배점, 실패 배점, 완전 성공/부분 성공 여부를 보고한다. 높은 총점이 남은 FAIL·미검증을 가리지 않게 한다.
